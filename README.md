# Project Description

The Personal Fitness Tracker Dashboard is a Python-based project that helps users record, analyze, and visualize their fitness activities.

Users can record activities such as Running, Yoga, Cycling, and Walking. The program calculates fitness metrics and generates graphs to help users understand their exercise habits.

# Features

- Log new fitness activities.
- Validate user inputs.
- Calculate total calories burned.
- Calculate average exercise duration.
- Calculate average daily calories burned.
- Calculate calories burned per minute.
- Filter activities by type or date range.
- Generate a fitness summary report.
- Display bar charts, line graphs, pie charts, and heatmaps.
- Save activity data in a CSV file.

# Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

# Project Files

- "fitness_tracker.py" — Main Python program.
- "fitness_activities.csv" — Fitness activity dataset.
- "README.md" — Project documentation.

The program also generates "fitness_report.csv" when a fitness report is created.


# Visualizations

The project provides four visualizations:

1. Bar Chart: Shows the total exercise duration for each activity type.
2. Line Graph: Shows calories burned over time.
3. Pie Chart: Shows the percentage distribution of recorded activities.
4. KDE Plot: Shows the correlation between exercise duration and calories burned.
